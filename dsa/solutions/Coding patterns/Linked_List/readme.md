# Linked List Manipulation 🔗

## Description
Linked Lists involve nodes pointing to the next (and possibly previous) node. Problems often involve pointer manipulation, cycle detection, and merging.

## Strategies

### 1. In-place Reversal
- **Concept**: Reverse a linked list (or a part of it) by changing `.next` pointers without using extra space.
- **Problems**:
    - Reverse Linked List
    - Reverse Linked List II
    - Palindrome Linked List

### 2. Fast & Slow Pointers (See Two Pointers)
- **Concept**: Use for cycle detection and finding the middle.
- **Problems**:
    - Middle of the Linked List
    - Linked List Cycle
    - Intersection of Two Linked Lists

### 3. Merging Lists
- **Concept**: Combine two sorted lists into one.
- **Problems**:
    - Merge Two Sorted Lists
    - Merge k Sorted Lists (with Heap)

### 4. Dummy Head
- **Concept**: Use a dummy node at the head to simplify edge cases (inserting at head, deleting head).
- **Problems**:
    - Remove Duplicates from Sorted List
    - Add Two Numbers
    - Swap Nodes in Pairs
    - Rotate List
