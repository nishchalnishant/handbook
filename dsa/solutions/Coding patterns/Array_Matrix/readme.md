# Array & Matrix 🔢

## Description
Problems involving 2D grids, rotations, and prefix sums.

## Strategies

### 1. Matrix Manipulation
- **Concept**: Rotating, transposing, or spiral traversal of 2D arrays.
- **Problems**:
    - Rotate Image
    - Spiral Matrix
    - Set Matrix Zeroes
    - Game of Life
    - Zigzag Conversion

### 2. Prefix Sum
- **Concept**: Precompute sums for O(1) range queries.
- **Problems**:
    - Range Sum Query 2D - Immutable
    - Product of Array Except Self

# String Manipulation 🧵

## Description
Operations on strings like anagrams, palindromes, and pattern matching.

## Strategies

### 1. Anagram Check
- **Concept**: Use hash map or frequency array (size 26) to count characters.
- **Problems**:
    - Valid Anagram
    - Group Anagrams

### 2. Palindrome Check
- **Concept**: Check if string reads same forward and backward.
- **Problems**:
    - Valid Palindrome

### 3. String Matching
- **Concept**: Finding occurrences of a pattern in text (KMP, Rabin-Karp).
- **Problems**:
    - Implement strStr()
    - Repeated Substring Pattern
