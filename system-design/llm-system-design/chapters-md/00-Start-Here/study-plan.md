# Study Plan

**One session = 25 minutes.** Tick a box only when you've done the closed-book recall step.
About 1–2 sessions a day, 5 days a week, gets you through in **5–6 weeks**.

**Spaced review rule:** each card gets revisited on **day 1, 3, 7 and 21** after you first study it. A review is 3 minutes: open the card's recall questions and answer them out loud. Mark anything you miss with `#review`.

Each chapter session follows the [[README#The 25-minute loop|25-minute loop]]: card → one deep section → recall.

## If you fall behind
Skip deep sections, not cards. Cards plus the concept map are **80% of the interview value in 20% of the time**. The deep sections are there for answering follow-ups.
